🏫 2026 1급 정교사 자격연수 강의용 USB 파일 모음
=====================================================

[실행 방법]
1. 인터넷이 연결된 크롬(Chrome) 또는 엣지(Edge) 브라우저를 엽니다.
2. '강의_발표자료_통합_챕터1_5.html' 파일을 더블 클릭하여 실행합니다.
3. 단축키 안내:
   - 'F' 키: 전체화면 전환
   - 'P' 키: 강사용 듀얼스크린 발표자 모드 (대형 스크립트 수정 및 자동저장)
   - 'N' 키: 하단 발표자 스크립트 노트 토글
   - '방향키 ▶ / ◀' 또는 'Space': 슬라이드 전환

[포함된 주요 파일]
- 강의_발표자료_통합_챕터1_5.html (통합 1~5 챕터 메인 발표자료)
- 디지털추리_통합진행.html (디지털 추리 체험 관제탑)
- N번방_사건_요약.mp4 (1챕터 동영상)
- 학교_딥페이크_뉴스_요약.mp4 (2챕터 동영상)
- 디지털추리_사건A_화면.html, 사건C_화면.html, 사건D_화면.html, 게임오프닝_사운드.html
- 강의스크립트_슬라이드별_복구정리.md (복구된 발표자 스크립트 모음)

※ 이 '강의용' 폴더 전체를 USB에 담아 가시면 됩니다.
